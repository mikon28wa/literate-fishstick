# literate-fishstick
Projektordner automatisch und ausschließlich *statisch* untersuchen. Das Programm liest Dateien, erstellt eine Architektur- und Risikoinventur und liefert pro Befund einen kopierbaren Untersuchungs- und Behebungsauftrag. **Es startet keinerlei Unit-Tests, Build-, Installations- oder Projektprogramme**
